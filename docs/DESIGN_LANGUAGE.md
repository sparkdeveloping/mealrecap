# MealRecap Design Language

MealRecap should feel like a premium food journal, not a fitness spreadsheet and not an AI toy.

## Principles

1. **Editorial, not dashboard-heavy**
   - Big daily number.
   - Quiet supporting stats.
   - Meal cards that feel like a magazine spread.

2. **Natural input first**
   - Chat it.
   - Say it.
   - Snap it.
   - Recap the whole day.

3. **No AI slop**
   - No purple-blue generic gradients.
   - No glowing orbs.
   - No fake futuristic UI.
   - No cluttered macro tables on the home screen.

4. **Trust over fake certainty**
   - Camera estimates should say “estimated portion,” not “weighed.”
   - Show confidence when helpful.
   - Make corrections fast.

5. **Motion should feel physical**
   - Horizontal day pagination.
   - Floating input buttons.
   - Calendar as an elegant jump layer.
   - Smooth spring transitions, no awkward pops.

## Visual system

- Background: warm cream.
- Primary text: deep espresso.
- Secondary text: warm gray.
- Accent: restrained green.
- Cards: warm white, subtle shadow, large radius.
- Typography: rounded, calm, high spacing.

## Core screens

1. Auth
2. Today / day pager
3. Meal thread
4. Camera analysis
5. Voice logging
6. Calendar
7. Paywall
8. Settings

## Product promise

> MealRecap turns messy meal memories into clean daily calories in, calories out, and net calories.
