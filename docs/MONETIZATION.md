# MealRecap Monetization

MealRecap uses a hook-first freemium model.

## StoreKit 2 product IDs

- Monthly: `com.sbj.mealrecap.pro.monthly`
- Yearly: `com.sbj.mealrecap.pro.yearly`

## Free tier

- Unlimited manual logging
- Calendar
- Basic daily calories in / calories out / net
- Basic HealthKit calories out
- 12 Smart Actions for first 7 days
- Then 6 Smart Actions per week

## Smart Action costs

- Text meal log: 1
- Voice meal log: 1
- Full-day recap: 2
- Photo meal analysis: 3

## Pro

- Unlimited text logs
- Unlimited voice logs
- Unlimited photo analysis
- Unlimited full-day recaps
- Food memory
- Saved usual meals
- Smart corrections
- Weekly insights
- Advanced HealthKit insights

## Paywall triggers

- After first successful photo scan
- After first successful day recap
- After 3 logged days
- When Smart Actions run out
- When tapping advanced insights

Do not hard-paywall on first launch. Let the user feel the magic first.
